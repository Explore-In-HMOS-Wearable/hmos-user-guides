# HMOS User Guides

Developer-facing guides for building on HarmonyOS (HMOS) and the Huawei
ecosystem. Each guide lives in its own folder, is written as a single
Markdown document, and carries its own images.

## Guides

| Guide | About |
|-------------------------------------|-------------|
| [Huawei&nbsp;Health&nbsp;Service&nbsp;Kit](./health-service-kit/) | Reading and writing users' health and fitness data from Huawei devices, through the Cloud-side REST API or the on-device SDK. |
| [Lite&nbsp;Wearable&nbsp;Technical&nbsp;Guide](./lite-wearable-technical-guide/) | Building applications for Lite Wearable sport watches on the ArkUI.Lite framework, from project setup through testing. |
